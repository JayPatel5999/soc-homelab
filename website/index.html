SOC Homelab

A single-host lab where I segment a network, run Active Directory and a SIEM, attack my own machines on purpose, and write up how each attack shows up in the logs.

View the GitHub repo LinkedIn

Why I built it

I am moving from software development into IT support and security operations. Reading about VLANs, firewalls, and detections only goes so far, so I built the environment and break it deliberately. Everything here is documented as it happens, including what goes wrong.

What is in it

Proxmox VE

One Dell Precision 3420 SFF runs every VM and container.

OPNsense

Routing, VLANs, DHCP, DNS, and Suricata between three network zones.

Active Directory

Windows Server 2022 domain controller with a joined Windows client.

Wazuh

Collects agent and firewall logs, raises alerts, and maps them to MITRE ATT&CK.

Isolated attack zone

Kali and vulnerable targets with no route to home or the internet.

Home services

Jellyfin and a NAS on their own VLAN, reached remotely only through Tailscale.

Network design

Three VLANs, all virtual inside Proxmox. Traffic from the attack zone has to pass the firewall, so it leaves evidence for the SIEM.

How detection works

Agents on the Windows and Linux machines and syslog from OPNsense feed one Wazuh server. Alerts are triaged and written up.

Detection scenarios

Scenario MITRE ATT&CK Status

Each write-up covers the attack, the evidence, the alert, the triage steps, and what the SIEM missed.
